# اختبار حفظ القرآن الكريم

تطبيق ويب تفاعلي (PWA) لاختبار حفظ القرآن الكريم، يعمل **بدون اتصال بالإنترنت** وببيانات قرآنية محلية كاملة. الواجهة عربية RTL بخُط Amiri لنص المصحف.

## المزايا

- **نطاقات مرنة:** اختيار سورة أو أكثر، نطاق صفحات، أجزاء، نطاقات مخصصة متعددة، أو اختيارات سريعة مثل «المفصل» و«جزء عمّ». تُضاف الاختيارات السريعة إلى النطاق الحالي بدلًا من استبداله، فيمكن الجمع بين «المفصل» ونطاق صفحات أو نطاق مخصص آخر.
- **دمج وتنقية تلقائية:** تُدمج كل معايير النطاق (اتحاد منطقي) وتُحذف الآيات المكررة.
- **توزيع عادل للأسئلة:** يُقسَّم النطاق إلى شرائح متطابقة تقريبًا، ويُختار سؤال عشوائي من كل شريحة. يدعم التوزيع على الصفحات أو الآيات أو تلقائيًا، مع خيار **ترتيب عشوائي للأسئلة** بدلًا من ترتيب المصحف؛ فيمكن أن يبدأ الاختبار من سورة في آخر النطاق ثم يعود لسورة في أوله مع بقاء التوزيع عادلًا.
- **واجهة اختبار تفاعلية:** عرض آية البداية أو **الصفحة كاملة** مع تمييز موضع بداية السؤال، التنقل بين الآيات أو الصفحات، العودة إلى بداية السؤال، وإخفاء/إظهار النص (وضع أعمى).
- **تقييم بالدرجات:** يحدد المختبر عدد الترددات والردود الخاطئة والتنبيهات. كل رد خاطئ = درجة، وكل تنبيه = نصف درجة، وكل تردد = ربع درجة، مع ملاحظات المختبر. على الهاتف يظهر شريط تقييم ثابت أسفل الشاشة، فيبقى زر «حفظ والتالي» والأخطاء في متناول الإبهام دون حاجة للتمرير.
- **ملخص نتائج شامل:** إجمالي الدرجات، متوسط الدرجات لكل سؤال، تفصيل الردود الخاطئة والتنبيهات والتردد، الأسئلة التي بدون أخطاء، السور التي تحتاج مراجعة، قسم بارز لملاحظات المختبر، وسجل تفصيلي قابل للطباعة.
- **تعليمات الاستخدام:** أيقونة مساعدة في الشريط العلوي تفتح نافذة منبثقة فيها دليل الاستخدام وخطواته وحساب الدرجات.
- **PWA أوفلاين بالكامل:** `vite-plugin-pwa` + Workbox لتخزين التطبيق والبيانات والخطوط مسبقًا. لا تُجرى أي طلبات API أثناء الاستخدام.
- **تصميم متجاوب:** يعمل على الجوال واللوحي وسطح المكتب، مع دعم كامل لـ `dir="rtl"`.

## طريقة الاستخدام

1. **اختر النطاق:** سورة أو أكثر، نطاق صفحات، أجزاء، نطاق مخصص، أو اختيار سريع مثل «المفصل». يمكن الجمع بين أكثر من نطاق وستُحذف التكرارات تلقائيًا.
2. **اضبط الاختبار:** حدد عدد الأسئلة وطريقة التوزيع (تلقائي موصى به)، واختر عرض «آية واحدة» أو «الصفحة كاملة»، وفعّل الترتيب العشوائي أو الوضع الأعمى إن أردت.
3. **ابدأ التسميع:** تنقّل بين الآيات أو الصفحات السابقة والتالية، وأظهر النص أو أخفه عند الحاجة. تظهر أيقونة «؟» في الشريط العلوي لفتح تعليمات الاستخدام في أي وقت.
4. **قيّم بالدرجات:** سجّل عدد الترددات والردود الخاطئة والتنبيهات من شريط التقييم الثابت أسفل الشاشة على الهاتف. الدرجة تعبّر عن الأخطاء وليست عن الإجابات الصحيحة، والأقل أفضل:
   - بدون أخطاء = ٠ درجة
   - تردد = ٠٫٢٥ درجة
   - تنبيه = ٠٫٥ درجة
   - رد خاطئ = ١ درجة
5. **راجع النتائج:** شاهد إجمالي الدرجات وتفصيلها والسور التي تحتاج مراجعة وملاحظات المختبر لكل سؤال، ثم أعد الاختبار بنفس النطاق أو ابدأ اختبارًا جديدًا.

> التقييم بيد المختبر بالكامل: هو من يحدد عدد الترددات والردود والتنبيهات لكل سؤال، ومنها تُحسب درجة السؤال ومجموع الاختبار.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يطبعه Vite.

### أوامر أخرى

```bash
npm run build      # بناء الإنتاج + توليد service worker
npm run preview    # معاينة نسخة الإنتاج
npm test           # اختبارات الوحدة (البيانات + التوزيع + حساب الدرجات)
npm run smoke      # اختبار E2E للتدفق الكامل (يتطلب تشغيل dev server على 4173)
npm run pwa        # اختبار PWA والعمل دون إنترنت (يتطلب preview على 4174)
npm run icons      # إعادة توليد أيقونات PWA من public/favicon.svg
```

> اختبارات E2E تستخدم Chrome/Edge المثبت. يمكن تحديد المسار عبر متغير البيئة `CHROME_PATH`.

## البيانات

بيانات القرآن منسوخة محليًا من مجلد `quran/` الأصلي إلى `src/data/quran/`:

- `surahs.json`: بيانات السور الـ114.
- `surahs/{1..114}.json`: الآيات مع رقم الآية العام، ورقمها داخل السورة، والصفحة، والجزء.

يتم استيراد البيانات في وقت البناء (`import.meta.glob`)، لذلك لا تحتاج إلى أي Network Requests أثناء التشغيل. إجمالي البيانات 6236 آية و604 صفحات و30 جزءًا.

## ملاحظات تقنية

- React 19 + Vite + TypeScript (strict) + Tailwind CSS 4.
- لا توجد مكتبات حالة خارجية؛ آلة الحالة مبنية بـ `useReducer` داخل `useTestEngine`.
- `generateQuestions` دالة نقية قابلة للاختبار ويقبل مولّد أرقام عشوائية (RNG) للحصول على نتائج حتمية في الاختبارات، مع خيار خلط ترتيب الأسئلة بعد توزيعها على الشرائح.
- وضع «الصفحة كاملة» يعرض جميع آيات الصفحة من فهرس الصفحات المحلي، ويُعلّم الآية التي يبدأ منها السؤال، مع تنقل مستقل بين الصفحات.
- ثبّت التطبيق من زر «تثبيت التطبيق» بعد أول تحميل، ثم يمكن تشغيله كاملًا دون إنترنت.
